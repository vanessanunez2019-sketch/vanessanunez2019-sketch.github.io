# Project Scope Statement

## Project Name

Vanna's Human Science & Human Resources Career Website

## Projected Start

September 22, 2026

## Completed By

October 1, 2026

## Projected Duration

10 calendar days

## Project Purpose

The purpose of this project is to create a simple professional website that introduces my academic background as a Human Science student and my interest in pursuing a career in Human Resources. The website will explain how my education, skills, experiences, and career interests connect to Human Resources. It will also give visitors an organized introduction to my future career goals and the type of work I hope to pursue.

## Project Description

I will design and develop a two-page professional website using HTML and CSS. The homepage will introduce me as a Human Science student and provide an overview of my academic interests and career goals. The second page will provide additional information about my educational background, interest in Human Resources, relevant skills and experiences, and plans for my future career.

The website will use one external CSS stylesheet to maintain consistent formatting, layout, and styling across both pages. The pages will include clear navigation so that visitors can move between the homepage and the second page.

The completed website will be published through GitHub Pages and stored in a public GitHub repository. The repository will also contain the required project documentation, including the project scope statement, project plan, and retrospective. The final repository will demonstrate my ability to organize a digital project, document the development process, and create a functional website.





## Desired Results

The completed project should:

- Provide a clear introduction to my academic background as a Human Science student.
- Explain my interest in Human Resources and how it connects to my education and career goals.
- Present relevant skills and experiences that relate to my future career interests.
- Provide visitors with an organized and professional overview of my career direction.
- Include a functional homepage and a second page with additional information.
- Allow visitors to navigate easily between both website pages.
- Use one external CSS stylesheet to create consistent styling across both pages.
- Be readable, organized, and visually professional.
- Be successfully published through GitHub Pages.
- Include all required project documentation in the GitHub repository.
- Demonstrate my ability to apply project-management, documentation, HTML, CSS, and GitHub skills learned in the course.
## Exclusions

The following items are outside the scope of this project:

- Creating a complete professional job-search website.
- Creating an online application or resume-submission system.
- Adding a database, user login system, or other advanced backend features.
- Creating a mobile application.
- Creating additional website pages beyond the required two pages.
- Providing actual Human Resources services or career counseling.
- Maintaining or regularly updating the website after the course project is completed.
- Creating advanced interactive features that are not required for the two-page website.
- Including features that are outside the requirements of the Project 03 assignment.

## Communication Needs

The primary communication for this project will be through the course Canvas site and instructor-provided assignment instructions. I will use Canvas announcements, assignment descriptions, and course materials to stay informed about project requirements and deadlines.

If clarification is needed, I will communicate with the instructor through Canvas or the instructor's preferred contact method. Project files and documentation will be organized in the GitHub repository so that the project materials remain accessible and organized.

I will also use GitHub to track changes to the website and project documentation. Regular commits will help document progress and maintain organized versions of the project files.

## Acceptance Criteria

The project will be considered complete when:

1. The GitHub repository is public and contains the completed project files.
2. The repository contains a clear and professional `README.md`.
3. The required project documentation is included in the repository.
4. The website contains a functioning `index.html` homepage.
5. The website contains a functioning `about.html` second page.
6. The two HTML pages are connected through working navigation.
7. Both pages use the same external `style.css` file.
8. The website provides information about my Human Science education, interest in Human Resources, skills, experiences, and career goals.
9. The website is successfully published through GitHub Pages.
10. The website is readable, organized, and visually consistent.
11. The completed project follows the requirements and submission instructions provided by the instructor.

## Constraints

The project has the following constraints:

- The project must be completed by October 1, 2026.
- The website must remain a simple two-page website.
- The website must use HTML and CSS as required for the project.
- The project must be stored in a public GitHub repository.
- The website must be published using GitHub Pages.
- The repository must follow the structure and documentation requirements provided by the instructor.
- The project must be completed within the time available for the course assignment.
- The project must remain focused on my Human Science and Human Resources career goals rather than expanding into unrelated topics.
