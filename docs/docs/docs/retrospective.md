# Project Retrospective

## What Went Well?

One thing that went well was being able to organize my career information into a professional website. Creating the website helped me practice using HTML, CSS, GitHub, and GitHub Pages. I also became more comfortable organizing files and making sure the different parts of the project worked together.

## What Went Wrong?

One challenge was learning some of the technical concepts while completing the project. Some parts of creating and organizing the website took longer than expected. Keeping track of multiple files and making sure the correct versions were saved was also a challenge.

## What Would I Do Differently?

If I completed a similar project again, I would start each part earlier and break the project into smaller tasks. I would also test the website more frequently instead of waiting until the end. This would make it easier to find and fix problems before the final submission.

## Overall Reflection

This project helped me understand that a digital project requires more than simply creating the final product. Planning, organization, testing, documentation, and version control are all important parts of successfully completing a project.
