# Project Plan

## Project Title

Vanna's Human Science & Human Resources Career Website

## Project Objective

The objective of this project is to create a simple two-page professional website that presents my educational background, Human Science major, interest in Human Resources, skills and experiences, and future career goals. The website will be hosted through GitHub Pages and will use HTML and CSS.

## Project Schedule

| Task | Description |
|---|---|
| 1. Plan the website | Define the website purpose, audience, pages, and content. |
| 2. Create homepage | Build the index.html homepage with career goals and introduction. |
| 3. Create second page | Build about.html with education, skills, experience, and future plans. |
| 4. Create stylesheet | Develop style.css to provide consistent formatting for both pages. |
| 5. Create documentation | Complete the scope, project plan, and retrospective documents. |
| 6. Test website | Check links, formatting, navigation, and page appearance. |
| 7. Publish website | Upload the project files to the GitHub repository and use GitHub Pages. |
| 8. Final review | Review all required files and prepare the final Canvas submission. |

## TAME Risk Analysis

### Technical

A technical risk is that HTML or CSS errors could cause the website to display incorrectly.

**Response:** Test both pages in a browser and correct broken links, formatting, or code errors before submitting.

### Administrative

An administrative risk is forgetting one of the required files or submission components.

**Response:** Use the assignment requirements as a checklist and review every required file before submitting.

### Market

A market risk is that the website may not communicate my career goals clearly to the intended audience.

**Response:** Use clear professional language and organize the information so visitors can easily understand my education, skills, experience, and career goals.

### Execution

An execution risk is running out of time while completing the website and documentation.

**Response:** Break the project into smaller tasks and complete the website, documentation, testing, and final submission separately.
