# Project Change Request

## Proposed Change

Add an embedded Google Map to the website that shows my hometown. The map would allow visitors to see the location of my hometown and learn more about where I am from.

## Reasons for the Change

The stakeholder requested this feature to provide visitors with additional information about my background and personal connection to my hometown. Adding a map would also make the website more informative and engaging for visitors.

## How This Change Will Add Value

Adding an embedded Google Map would give visitors a visual way to learn about where I am from. It would add personal context to the website and make the project more interactive without changing the main purpose of the website.

## How This Change Will Affect the Constraints

### Time

The change would require some additional time to add, test, and verify the Google Map on the website. The time impact should be relatively small because the feature is limited to one embedded map.

### Quality

The Google Map could improve the quality of the website by adding an interactive and visually informative feature. However, the map would need to be tested to make sure it displays correctly and does not interfere with the website's layout or navigation.

### Budget

The change should have little to no direct budget impact because an embedded Google Map can be added without purchasing additional website development services. Any potential costs associated with the map would need to be considered if the feature required services beyond the project's existing resources.
